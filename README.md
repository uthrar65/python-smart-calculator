# Python Smart Calculator

My first Python project as a B.Sc. Artificial Intelligence student.

## About the Project
A beginner-friendly calculator built using Python. It performs basic arithmetic operations and compares two numbers.

## Features
- Addition
- Subtraction
- Multiplication
- Division
- Remainder
- Power
- Number comparison
- Division-by-zero protection

## Technologies Used
- Python 3

## Concepts Learned
- Variables
- User Input
- Data Types
- Arithmetic Operators
- Comparison Operators
- Conditional Statements (`if`, `else`)

## How to Run

1. Download or clone this repository.
2. Open `calculator.py`.
3. Run it using Python.
